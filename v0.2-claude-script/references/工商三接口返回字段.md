# 工商三接口返回字段（来源：用户提供的万联易达开发者中心接口页面；字段含义除页面明示外标【推断】）

三接口的 `model` 均为数组；另有统一包装字段：`total`、`succeed`、`errMsg`、`message`、`errCode`；记录内另有 `code`、`errorMsg`。请求参数：D 用 `entName`/`creditCode`/`forceQuery`/`apiCode`；B 用 `entityName`/`creditCode`/`organizationCode`/`registerCode`/`apiCode`/`id`；T 用 `entName`/`creditCode`/`organizationCode`/`regno`/`apiCode`/`id`；统一要求 Header `appCode`；名称、信用代码、组织机构代码、注册号四选一。

## D 企业详细信息查询（POST /otsCheck/companyDetailCheck，对应 enterprise-get-company-detail）
code, errorMsg, historyNames（曾用名）, capital（注册资本，示例“200.000000万”）, realCapital（示例“200万元”）, companyName, creditNo（统一社会信用代码）, orgCode, companyCode（【推断】工商注册号）, companyType（示例“有限责任公司(自然人独资)(1151)”）, companyStatus（示例“存续（在营、开业、在册）”）, legalPerson, legalPersonType（示例“自然人”）, establishDate, operationStartdate, operationEnddate（示例 null）, businessScope, industry, authority（登记机关）, companyAddress, province/city/district 及 provinceCode/cityCode/districtCode, lastUpdatedTime。

## B 数据宝企业基础信息核验V2（对应 databao-company-basic-info-check-v2，CompanyBasicInfoVo）
code, errorMsg, entityName, creditCode, organizationCode, shortName, address, registerCapital（单位：万）, actualCapital, currency, entityStatus（1存续 2注销 3吊销 4撤销 5迁出 6迁入 7清算中 8停业 9其他 10空 11歇业 12备案关闭 13已取销非法人会社组织 14涉嫌非法会社组织）, entityType, entType（企业分类）, tagName（小微/中型/大型）, legalPerson, legalPersonType（P个人/E企业）, registerDate, registerDepartment, businessStartTime/businessEndTime（YYYY-MM-DD）, checkDate, employeeCnt, businessScope, revokeDate/revokeReason, cancelDate/cancelReason, province, city, districtCode, isIPO（1是/2否）, listDetail[listDate, listedCd, endDate, listedType], isHitech（1是/0否）, historyName（对象）, industryCode, industryName, businessAddress, registerCode。

## T 数据宝企业详情信息核验V2（对应 databao-company-details-check-v2，CompanyDetailsVo）
code, errorMsg, 以及三个子对象：
- basic（BasicInfo）：regno, esdate, creditcode, zsopscope, dom, enttype, ancheyear, opfrom, regcapcur, regorgdistrict, orgcodes, entitytype, regcap, postalcode, entname, regorg, regorgcity, regorgprovince, entname_old, entstatus, frname, apprdate, opto, revdate, revoke_reason, candate, cancel_reason。页面只给了示例键、没有逐字段说明，含义按字段名对应（【推断】：esdate 成立日期、dom 住所、opfrom/opto 经营期限起止、apprdate 核准日期、ancheyear 最后年检年度、entname_old 曾用名、frname 法定代表人、regcap/regcapcur 注册资本及币种、zsopscope 经营范围类字段）。
- person（PersonInfo，高管）：personamount, pername, entname, position。
- techEnt（TechEntInfo，科技企业认证）：cancelDate, districtCode, certificateYear, endDate, certificateStateCode, certificateLevel, publishDate, checkDate, webPublicStatus, certificateState, certificateNumber, entityName, district, isHistory, startDate, certificateType。

## 与 v20 的差异
v20 的 business skill 只写了每个接口返回的大类（身份、状态、经营范围……）；v22 把三个接口的每个返回字段都归入清单的 J01–J29，字段缺失/为空/接口失败的统一记 N R07 并写明接口名。
