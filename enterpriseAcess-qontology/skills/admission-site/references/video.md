# 办公视频

1. 先按采样帧观察第 0 秒位置，区分大门、入口、前台、工位区和无法辨认。再分别记录工位、电脑、人员、可读招牌，以及可定位的画面变化。每项标对应时间点。
2. E01 用解码报告的总时长和实际采样区间。E03 可以描述采样帧之间可见变化及范围。离散帧不足以证明全程连续或准确定位切点。
3. E05 有明确物理异常时写帧和细节，例如屏幕边框或绿幕边缘。采样未见明确异常时写“采样帧未见”，真实性另行核验。E10 需独立核验或明确物理证据，单凭无人、画面整齐、招牌差异或视觉印象留空。
4. E08 入口起拍与随后全程连续都得到确认才为 true。第 0 秒明确已在工位区可填 false，连续性未知则留空。E09 记录能够辨认的关键场景。
5. 招牌先逐字读原文。集团短名需要主体归属证据，全文与申报主体不同则保留原文和差异。
