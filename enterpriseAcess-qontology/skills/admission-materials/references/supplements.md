# 补充材料

- PDF 逐页按标题分类。税收完税证明、无欠税证明、社会保险费缴纳证明和增值税专用发票分别登记。混合 PDF 逐页标注实际文种，上传到发票槽位的完税证明只支持完税事实。
- 增值税发票读取双方身份、品名、项目、金额和日期。上下游合同读取双方、服务、交付、计酬、金额及履行期。合同与发票配套须有双方、交易内容和日期或金额对应。关联方判断需有可核查的主体关联。
- 社保、完税及无欠税证明分别记录单位或纳税人、信用代码、所属期或出具日、章及可见异常。与申报和执照的名称、信用代码逐项核对。近三月结论需要业务申请日。
- 网页证据取本次实读正文，网页版权主体或公开介绍可支持网站归属和所披露的主营业务。独立记录页面是否成功读取、申报企业归属和披露内容。仅提供 URL 时保留缺口。
