# 营业执照

- B01 至 B08 逐字抄对应栏。先定位「成立日期」标签和值区，证据同时引标签及日期。空白或本栏未设置，说明具体位置后留空。遮挡或模糊另记不可辨。营业期限起始、页底发证日和工商成立日各归原栏。
- B05、B05-1 分别读取营业期限起止。截止写长期时照录。B11、B16、B22 依赖业务申请日，按清单和本体口径计算或留空。
- B12 同时查看底色、边框、文字、图案和印章。全为黑白灰时填 false。判断 true 前回看声称有色的位置，记录实际色相。B13 看公司鲜章，B27 看登记机关章。灰度登记章可使 B27 为 true，B12 和 B13 依据各自画面。
- B18、B19 检查名称与类型两栏。任一明确写分公司或合伙可确定对应类型，两栏均可读且未命中才可排除。主体独立用工资格按 qOntology 定义与核验记录判断。
- B23 先写可见异常，如成立日期清楚空白、名称错字、模板标记。无法定性留空并写原因。证照样式及印迹主要用于观察，官方存续状态需独立查询。
