## 用工场景与经营范围分别判断

用工场景描述本次人员实际从事的工作，经营范围描述主体的登记经营内容，两者证据与取值不可互相代替。规则比较枚举编码时，项目整句原文只能作证据，不能直接充当枚举值。

| 本次岗位/交付确实从事的业务 | 用工场景选项/编码示例 | 经营范围类目选项/编码示例（仅对应登记范围有证据时） |
|---|---|---|
| 药品、医疗器械销售，医药推广等 | 医药 / pharma | 医药及医疗器械销售 / pharma_medical_device_sales；医药科技 / pharma_tech |
| 主播介绍商品、直播促销、带货转化 | 直播带货 / live_commerce | 电商直播带货（不含音视频制作）/ ecommerce_live_stream |
| 本次是直播服务，未涉及带货 | 直播 / live_stream | 按登记范围和当次选项另判 |
| 影视传媒的拍摄、制作、影视业务执行 | 影视 / film_tv | 影视传媒 / film_media |
| 律所法律咨询、诉讼代理等业务 | 律所 / law_firm | 律师及会计师事务所 / law_accounting_firm |
| 会计师事务所审计、会计专业业务 | 会计 / accounting_firm | 律师及会计师事务所 / law_accounting_firm |
| 保险产品销售、保险经纪、保险代理服务 | 保险经纪 / insurance_broker | 保险经纪代理 / insurance_agency |

本次用工场景属于以上行业业务时，按实际工作提交相应场景值，不能以“临时”“推广”“辅助”“持牌”等词跳过类别。直播带货不是一般音视频剪辑；保险销售也不是不涉及行业业务的普通地推。

仅企业名称或经营范围命中这些行业，但岗位确为与本行业业务无关的临时辅助工作（如律所招聘会现场引导、保险公司的临时会场布置），不能据主体行业把本次岗位也填成敏感场景。按本次岗位与可选项判断场景，并保留行业事实及必要的人工核实提醒；该提醒不改引擎结论。

实际业务类别、用工场景、经营范围类目是不同维度，编码不能互换。例如 actual_business_category 的定义未列医药选项，不能把 pharma 塞进去；同时仍须向规则引用的用工场景键提交 pharma，不得因此整组跳过。
