# admission-noshell-dou-1-1 / admission-dou-1-1-category

# 业务分类单选（按语义判断）

适用于本次定义中**选项是业务类别**的枚举键（如实际业务类别、所属行业、用工场景）。`combine.py plan` 对这类键打印 `CATEGORY_TASK` 任务卡：本次原文、各选项对应的规则。编码一律取本次 enum。

分类值的含义是“申报的业务属于哪一类”，**不是“已核实违法”**：不需要外部核查结论；项目内容、交付要求把业务说清楚了，就足以分类。

## 核心原则：读懂业务，不做字词匹配

- **判断的是语义，不是字面。** 原文出现某个选项名或相关词，不等于业务属于该类；原文没出现任何选项名，也不排除该类。要回答的是“这些人实际在做一件什么事”，再看哪个选项的含义最贴切。
- **选项的含义以本次定义为准。** 读 label、comment 和 enum 中文名理解每个选项指什么、边界在哪；不套用固定的对照表或历史编码。
- **没有固定优先顺序。** 不按“某类先于某类”逐层筛选；几个选项都沾边时，选最能概括业务核心实质的那一项，并在依据里说明为什么不是另一项。
- **脚本不替你定值。** 脚本不做词表扫描、不按命中词拦截或放行；分类完全由你的理解决定，你对结果负责。

## 判断方法

**1. 用自己的话说清业务**（写进 set 依据的“机制：”后面）。主要依据项目内容 A08、交付要求 A07，其次项目简介 A09、岗位名称 A13，把以下几点讲明白（原文没写的就说没写，不臆补）：

- 人员实际做什么、面向谁；
- 经手或提供的是什么产品/服务；
- 怎么获得报酬、钱怎么流转；
- 在什么场所、什么条件下作业。

企业名称、经营范围、开票类目只作辅助背景，不能用宽泛的登记类目盖过项目里写明的实际业务，也不能仅凭主体所属行业给本次岗位定类。

**2. 逐项对照选项含义**。对每个可能的选项，问“本次业务在实质上是不是这件事”，估计把握。注意整体语义：

- 句子的指向与语气：否定（“不涉及…”“严禁…”）、宣传/防范（反诈宣传、普法）、为某行业提供工具或配套（为银行开发系统、为工地做设计）与亲自从事该业务是不同的事；
- 措辞与实质不一致时看实质：自称“咨询”“技术服务”“推广”“临时兼职”，而描述的工作内容就是某类业务本身，按实质归类；
- 材料之间有矛盾（如合同另写“不按人数计酬”，项目原文却写明了按人数计酬）时，列出双方原文、记 conflicts，按你对真实业务的判断选，并写明取舍理由。

**3. 选定并自查**。选最贴切的一项；交之前换个角度再读一遍原文：如果把这段业务描述给一个懂行的人，他会不会认同这个归类？有疑点就写进依据。

- 最高一项把握过半才 set；都不过半，skip R10，依据里写最接近的两项、各自把握和具体缺口。
- 业务内容空缺、不可读、来源冲突无法辨识时，不用一般类兜底，skip 并写明缺口。
- 选一般类同样要有正面理由：业务可辨识，且你确认它在实质上不属于任何特殊类别；不能因为“没看到敏感词”就选一般类。

## 提交

只交 `set`，依据里的条目就是映射，不必另写 map；set 落盘，后续 build 不必重提：

```
"set":{"<对象.属性>":["<选项编码>","派生:A08,A07｜<选项中文>｜置信度约N%｜机制：<第 1 步的描述>；<反证及取舍，没有就不写>"]}
```

只交一个编码：不交数组、拼接值、中文整句。

## 不同分类维度分别判断

用工场景看本次人员实际从事的工作；所属行业、经营范围类目等看各自定义所指的对象（如登记范围）。同一份原文在不同维度上可能落在不同选项，各自按本次定义的选项含义判断；编码不互换，某维度缺合适选项不影响其他维度提交。

## 示例（只说明思路，不是对照表）

| 原文（节选） | 语义理解 | 结论 |
|---|---|---|
| 为银行开发理财产品管理系统的后台软件，交付源代码 | 人员做软件开发，交付物是代码；不向任何人推介理财 | 软件/一般类，而非理财 |
| 面向个人客户提供“资产规划咨询”，推荐合适的基金组合并跟进认购 | 名为咨询，实为向个人推介并促成金融产品购买 | 理财类 |
| 组建推广团队，新成员的加入带来上级奖励，团队越大收入越高 | 没出现“返利”“人头”字样，但报酬实质随发展人数增长 | 按人数计酬的传销类 |
| 开发客服工单系统，系统禁止用于催收场景 | 提到催收只是限制用途，人员做的是开发 | 一般类 |
| 为平台付费用户提供陪伴聊天，按通话时长结算 | 交付的是付费情感陪聊服务本身 | 对应本次定义中涵盖付费陪聊的选项 |
| 化工企业招聘临时行政文员，负责文件整理 | 主体是化工，但本次岗位不接触危化品生产 | 按岗位实际工作归类，保留行业提醒 |
