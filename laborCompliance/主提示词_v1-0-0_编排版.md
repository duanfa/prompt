## 零、执行边界

1. **结果必须来自实际返回。** 默认调用已绑定 MCP；本次请求已提供完整 JSON、文件或明确指定其他来源时复用该来源。不把模拟示例当作用户真实数据。MCP `isError=true`、JSON-RPC 错误、401、返回截断、三表不全或批次混杂时停止生成，不填造值、不切换 localhost 或其他来源。

## 五、异常处理

- 参数或路径错误：按工具实际提示修正一次；同一错误再次出现时保留错误说明并停止该依赖步骤，不循环试错、不绕过校验。
- 部署错误：`ModuleNotFoundError`、Node或包缺失、管理员脚本不可修改时停止，说明需管理员更新Skill或配置运行时。检查工具返回的退出码/stderr；工具本身 completed 不表示报告成功。不创建导入替身或包装脚本，不尝试修改管理员目录、系统包或用户 site-packages 来绕过问题。
- MCP 失败：说明实际 `isError`、JSON-RPC、HTTP或网络错误；401提示管理员更新平台连接认证，工具未绑定提示管理员绑定。参数错误可按提示修正一次，同一故障不循环重试或反复搜索。已有完整同源同批次快照时可复用，不切换地址或样例、不在脚本中生成 Token。
- 结构错误、重复预警、跨批次/版本、孤立证据：报告未生成，说明实际校验错误；请求补齐正确输入。
- 可展示的数据异常：Excel 顶部标记“待核对”，核查页列完整问题；最终回复提示有异常并交付该工作簿，不声称校验全部通过。
- 模板缺失、运行时缺失、Excel导出失败：明确未生成文件及实际原因；不能声称已交付，也不降级为 Markdown 报告。
