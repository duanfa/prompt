# 规则及报告映射

## V1.0 规则

| 规则 | 条件（同时满足） | 预警 |
| --- | --- | --- |
| R01 | 最近3个完整自然月每月有效发放金额>0；整个观察期波动率≤金额容差；存在同一固定日使每月窗口金额占比均≥80% | 普通，疑似固定用工特征 |
| R02 | 将R01同一算法整体扩展至最近6个完整自然月；六个月共同满足金额及日期条件 | 重点，主要规则取R02，不重复增加R01预警 |
| R03 | 最近3个完整自然月，H为命中R01去重人数（含R02），U为全部有效发放去重人数；H≥人数阈值且H/U≥占比阈值 | 客户重点核查 |

默认建议参数为金额容差5%、日期窗口±3日、窗口占比80%、R03人数10、占比30%；展示时优先使用结果内快照。除原文3个月及5%外，其余阈值正式启用前需历史回测与产品确认。当前 SQL 无“窗口占比阈值”字段，80%来自V1.0规则说明，不能把 `min_window_ratio`（实际最小占比）当作阈值。

月金额为成功发放流水的应发金额，同客户同灵工不同项目合并、同月分笔合并、业务流水ID去重。金额波动率=(最高月金额−最低月金额)/最低月金额。没有发放则中断连续性；资料缺失为无法评估。

日期规则枚举 d=1…31；某月无该日时用该月末日，取当月锚点±窗口天数并截断至月内。窗口金额/月金额须各月均达标。多个d可用时取“各月最低占比”最高者，仍相同取较小d。月度证据只有汇总，不包含全部候选锚点或源流水日期；只能核对给定锚点的窗口一致性，不能声称验证了枚举最优性。

运行按月、首次至少回溯6完整月。对象、规则版本、观察期保存快照。首次命中提醒；普通升重点追加提醒；持续命中仅更新。仅凭 `first_hit_time/last_hit_time/is_upgraded` 可描述当前快照，不能声称报告生成动作已经发送提醒。

状态为待核查→核查中→已关闭。结论枚举：存在风险、合理业务场景、证据不足。关闭需结论及依据；报告样例还要求负责人等人工处理内容。三表缺少的后续措施和原流水，必须说明未提供。

## 报告栏目及来源

| 报告栏目 | 数据及注意事项 |
| --- | --- |
| 基准日、版本、观察期、币种、模拟标识 | 使用 `ds/rule_version/obs_start_month/obs_end_month/currency`，及来源显式模拟标记；R02显示各自6月观察期 |
| 已评估客户 | 客户汇总的 customer_id 去重计数，范围限当前响应 |
| 客户聚集预警 | 汇总中 `is_customer_warn=1` 的客户＋币种行数 |
| 客户－灵工预警数 | 完整人员明细行数，与汇总H逐客户核对，已含R02 |
| 重点人员预警数 | `main_rule=R02` 行数，与汇总r02人数核对 |
| 涉及金额 | 客户 `involved_amount` 按币种汇总；单列人员 `total_amount_3m` 作为其中金额 |
| 客户汇总 | 客户ID/名称、币种、U、H、占比、R02人数、金额、R03标志、优先级及人员状态计数 |
| 全部人员明细 | 预警ID、客户、灵工ID、脱敏姓名、币种、主要规则、优先级、观察期/覆盖月数、最低/最高月金额、波动率、近3月金额、固定日/窗口、最小窗口占比、升级及状态 |
| 月度证据 | 每条预警的全部月份，显示月份/月序、有效发放标志、月金额/笔数、当月锚点、窗口起止/金额/占比；不能只给W001示例 |
| 核查处理 | 客户和人员分别展示状态、负责人、结论、依据、关闭时间；未知为未提供；重点与普通区分安排核查 |
| 参数与局限 | 金额容差/日期窗口/人数阈值/比例阈值快照，未提供的上游数据与异常范围 |

R03未命中不等于人员无预警；已关闭不等于历史命中记录可删除。人员状态只由人员行计数，客户状态单独展示，不能将两类工单合并为同一人数。

## 新版模板映射

| 工作表 | 写入位置 |
| --- | --- |
| 灵工固定用工特征风控报告 | C4为批次日期，F4为观察期，M4为版本及币种；A7/D7/G7/J7/M7为统计卡片，分币种金额从第12行开始，异常列在下方 |
| 客户风险汇总 | 第2行表头，第3行起客户数据；A:I保留模板原栏目，J:M替换占位列为币种、核查状态、负责人、核查结论；N:P保留统计说明。客户表下方按实际条数放核查依据、关闭时间、观察期、阈值、人员状态计数及人员金额 |
| 命中人员明细 | 第2行表头，第3行起全部预警，R02排前；L:P替换占位列为最低窗口占比、核查状态、负责人、核查结论、核查依据；Q:AD保留币种、关闭时间及其余SQL字段。黄色字段可填写，其他字段为上游快照 |
| 月度证据 | 每条预警复用一组月份卡片，R01显示3月、R02显示6月；期内缺月明确显示证据缺失。所有卡片下方为可筛选的17字段完整月证据表，不能仅输出W001样例 |

不再添加旧规则页或“核查与参数”页。模板示例判定公式含固定阈值，生成时清除，客户预警和优先级使用接口原值；汇总金额、人员状态计数保留可重算公式。人工核查信息随所属表格整行排序，客户参数表按客户ID＋币种统计人员记录。

## 核对边界

- 金额6000/6150/6300，波动率5%可命中；6301超过5%不支持命中。核对未四舍五入的底层值，显示精度不改变阈值。
- 同锚点窗口可覆盖7/10/13日，2/15/28日无法共用±3日窗口；无该日用月末，窗口不得跨月。
- U40/H12满足30%，H11不满足；人数与占比条件必须同时满足。
- R02需要六个月共同稳定，不能只把两个独立三个月的结论拼成六个月。
- 不同客户的相同 worker_id 分别成预警；不同ds或版本分别出报告；不同币种分别计金额。
- 原规则未定义风险评分、自动阻断或劳动关系法律结论，报告不能自行增加。
